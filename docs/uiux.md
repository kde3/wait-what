# UI/UX 개발 규칙

## 컴포넌트
- 컴포넌트는 **HeroUI**를 우선적으로 사용하고, 이용할 컴포넌트가 없을 경우에만 직접 구현해서 사용한다.
- 여러 화면에서 반복해서 사용하는 컴포넌트 또는 UI 조합은 components/ui/에 공통 컴포넌트로 만들어 재사용한다.
- 해당 화면에서 사용하는 컴포넌트는 각 화면에 해당하는 폴더를 만들고, 그 안에 만들어서 사용한다.

## 아이콘
- 텍스트나 이모지로 아이콘을 대신하지 않으며, **pixelarticons**를 사용한다.

## 폰트
| 폰트 | 쓰이는 곳 |
|---|---|
| Mona | 기본 UI, 제목, 버튼, 라벨 |
| Pretendard | 설명문, 보조 문구 |

## 색상
- 색상은 반드시 CSS 변수(--palette-*)를 사용하며, 컴포넌트에 색상 값을 직접 작성하지 않는다.
- 사용 가능한 색상 팔레트는 Storybook의 Foundations/Colors에서 확인할 수 있도록 관리한다.
