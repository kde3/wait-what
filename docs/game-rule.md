# 게임 모드 규칙

## 1. 클래식 모드

```
round 0: text (각자 제시어 작성)
  ↓  전원 제출 또는 시간 종료
round 1: image (앞사람의 제시어를 보고 그림 생성)
  ↓
round 2: text (앞사람의 그림을 보고 제시어 추측)
  ↓
  text / image 를 번갈아 반복 (총 라운드 = 참가 인원 수)
  ↓
finished (앨범 공개 — 내 제시어가 어떻게 변해갔는지)
```

## 2. 스피드 퀴즈 모드

```
play (생성과 맞추기에 하나의 통합 제한시간 사용)
  ├─ 출제자: 키워드를 보고 그림 생성 → 생성 완료 시 자동 제출
  └─ 맞추는 사람: 그림 제출 여부와 관계없이 언제든 정답 입력
  ├─ 먼저 맞힌 사람 → 맞힌 사람 +1점, 출제자도 +1점
  └─ 시간 초과 → 출제자 -1점
  ↓
reveal (6초간 키워드와 그림 공개)
  ↓
  설정한 라운드 수만큼 반복
  ↓
finished (점수판 공개)
```

- 출제자는 매 라운드 돌아가며 맡는다.
- 팀 모드에서는 개인 점수 대신 맞힌 사람의 팀에 +1점이 들어간다.

## 3. 임포스터 모드
```
turns (차례대로 그림 생성)
  ↓
vote (임포스터 투표)          ← 새로 추가
  ├─ 지목 실패 → 임포스터 승리 (즉시 종료)
  └─ 지목 성공 → guess (임포스터가 키워드 추리)
                   ├─ 맞힘 → 임포스터 승리
                   └─ 틀림/시간초과 → 크루 승리
```
