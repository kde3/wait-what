## 각 화면 기능별

### 공통
#### 볼륨
- [x] 볼륨 조절 (헤더 팝오버 · BGM·효과음 공통 · 0～100%)
- [x] 음소거와 볼륨 독립 동작 (음소거 해제 시 이전 볼륨 복원)

### 메인
- [x] 공개방 목록 실시간 갱신
- [x] 초대 코드로 입장
- [x] 아무 공개방 입장 가능한 버튼 (랜덤 입장)
- [x] 프로필 변경 (아바타 옆 회전 버튼)
- [ ] 풀방·게임중인 방은 목록에서 숨기기
- [x] 방 정원 12명 (`MAX_PLAYERS` 상수 · 서버가 클라이언트에 내려줌)
- [ ] 방장이 방 만들 때 정원 직접 선택 (선태)
- [ ] 공개방은 닉네임만 지정하면 바로 입장

### 대기방
- [x] 공개방 초대하기 QR 접속
- [x] 공개방 초대하기 URL
- [x] 공개방 초대하기 초대코드
- [x] 비번방 초대하기 QR 접속 → 비번 입력
- [x] 비번방 초대하기 URL → 비번 입력
- [x] 비번방 초대하기 초대코드 → 비번 입력
- [x] 방장이 나가면 방장 넘어감 (로비·게임중·결과 전 단계)
- [x] 방에 사람이 아무도 없을 때 방 삭제
- [ ] 방장 넘기기
- [ ] 비번 변경 가능 (선택사항)
- [ ] 결과에서 대기방으로 각자 돌아오는 중이면 게임 시작 불가 (전원 합류 후 시작)

### 게임
#### (1) 클래식

#### (2) 스피드 퀴즈
- [x] 돌아가면서 그릴지 / 한 명 고정으로 그릴지 + 고정 시 방장이 지정
- [ ] 출제자 지정 옵션 제거 (팀전에서 애매해지기 때문) — 항상 돌아가며 출제
- [ ] 어려운 키워드는 점수를 더 주기 (선택사항)
- [x] 이미지 생성과 정답 맞히기에 통합 제한시간을 사용하고, 생성 완료 시 자동 제출 · 생성 전에도 정답 입력 허용

#### (3) 임포스터
- [x] 차례대로 그림 생성 → 임포스터 투표 → 지목 실패 시 임포스터 승리 / 지목 성공 시 임포스터에게 키워드 추리 기회
- [x] 최다 득표자가 지목되고, 표가 갈리면 아무도 지목되지 않는다 (임포스터 승리)
- [x] 자기 자신과 중퇴자에게는 투표할 수 없고, 전원이 투표하면 시간이 남아도 즉시 집계
- [x] 임포스터 전원 이탈 → 시민 승리
- [x] 시민 전원 이탈 → 임포스터 승리
- [x] 사회자 옵션 제거 (전원 참여 · 최소 3명)
- [x] 채팅 (게임 중 대화 · 전원 제한 없이 자유롭게)
- [x] 3명 이상부터 시작 가능 (인원 미달이면 시작 버튼 비활성 + 안내 문구)
- [x] 그림을 생성하지 않으면 시간 초과로 넘어감 (건너뜀으로 표시)
- [x] 임포스터 타임아웃 시 마지막 생성 이미지를 사용하고, 시간 종료 후 도착한 생성 응답은 폐기

#### (4) 카오스
- [x] 결과에서 원본 이미지와 각 사용자가 본 효과 적용 이미지를 비교 표시

#### 결과
- [x] "새 게임"은 방장만 누를 수 있게 (나가기는 모두 가능)
- [ ] 결과 공유를 GIF로 (갈틱폰 방식) — **보류**

## AI 연동
- [x] 이미지 생성 API (`POST /generate`) — 모든 그림은 항상 생성
- [x] 이미지 저장·서빙 (`/api/image/:id`, 1시간 TTL, 방 삭제 시 회수)
- [x] 키 없을 때 목업 폴백
- [x] 키는 백엔드 env에만 (프론트 노출 없음)
- [x] 난이도 옵션 (쉬움/보통/어려움) — 전 모드 공통, 모든 이미지 생성 요청에 `easy`/`normal`/`hard`로 전달
- [ ] 평가 API (`POST /evaluate`) — 코드는 있으나 호출부 없음 (릴레이 제거로 소비처 사라짐)

## 버그 & 개선
- [x] 같은 닉네임이 있으면 "나"라고 표시되는 것
- [x] 방을 찾을 수 없으면 가운데 모달창 + 메인으로 가는 버튼
- [x] 방에 머무르기 가능하도록 (머무르기/나가기, 각자 선택)
- [x] 중퇴 유저 발생 시 처리 (재접속 유예 3초)
- [x] 협동 모드 서버 프로세스 크래시 (stateKey가 coop 그룹 구조 오인)
- [x] 이미지가 프론트 origin으로 풀려 404 나던 것
- [x] QR 다크모드 대비 없어 스캔 불가 (1.11:1 → 21:1)
- [x] 재연결 중인데 "끊겼다"고 표시되던 것 → "연결 중" + 실패 시 모달
- [x] 제출 시 화면 가리던 것 → 내용 유지하고 입력만 비활성화
- [x] 팀 전멸 시 게임이 안 끝나던 것 → 남은 팀으로 계속 진행
- [x] 중퇴자 이름이 결과에서 `?`로 뜨던 것 → 방 단위 닉네임 기록으로 스냅샷
- [x] 제출 후 수정 버튼이 잘 안 보이던 것 → 제출 버튼 자리에서 그대로 전환
- [ ] 모든 알림은 토스트 메시지로 통일 (현재 토스트 3곳 / 인라인 8곳 혼재)
- [ ] 풀방이거나 게임 시작한 방은 공개방 목록에 조회 안 되도록
- [ ] 중퇴한 플레이어를 중퇴로 표시 (현재는 명단에서 사라지기만 함)
- [x] 방 만들 때 인원 수 제한 (12명)
- [x] 모바일에서 배경음악 멈추지 않고 계속 작동하지 않도록 하기
    (visibilitychange / pagehide / pageshow / freeze 대응, 음소거 상태 존중)
- [x] 임포스터 모드의 좁은 채팅 패널에서 전송 버튼이 박스 밖으로 넘치던 문제
- [x] 카오스 캐릭터 선택 후 효과 설명을 5초간 보여주고 플레이 중에도 작게 유지
- [x] 모든 모드의 이미지를 보고 제시어를 맞히는 단계에서 이미지 드래그 방지
