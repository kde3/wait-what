## 버그픽스

- [x] 같은 닉네임이 있으면 "나"라고 표시되는 것
- [x] 방을 찾을 수 없으면 가운데 모달창 + 메인으로 가는 버튼
- [x] 방에 머무르기 가능하도록 (머무르기/나가기, 각자 선택)
- [x] 중퇴 유저 발생 시 처리 (재접속 유예 3초)
- [x] 협동 모드 서버 프로세스 크래시 (stateKey가 coop 그룹 구조 오인)
- [x] 이미지가 프론트 origin으로 풀려 404 나던 것
- [x] QR 다크모드 대비 없어 스캔 불가 (1.11:1 → 21:1)
- [x] 재연결 중인데 "끊겼다"고 표시되던 것 → "연결 중" + 실패 시 모달
- [x] 제출 시 화면 가리던 것 → 내용 유지하고 입력만 비활성화
- [x] 팀 전멸 시 게임이 안 끝나던 것 → 남은 팀으로 계속 진행
- [x] 중퇴자 이름이 결과에서 `?`로 뜨던 것 → 방 단위 닉네임 기록으로 스냅샷
- [x] 제출 후 수정 버튼이 잘 안 보이던 것 → 제출 버튼 자리에서 그대로 전환
- [ ] 모든 알림은 토스트 메시지로 통일 (현재 토스트 3곳 / 인라인 8곳 혼재)
- [ ] 풀방이거나 게임 시작한 방은 공개방 목록에 조회 안 되도록
- [x] 방 만들 때 인원 수 제한 (12명)
- [x] 모바일에서 배경음악 멈추지 않고 계속 작동하지 않도록 하기
    (visibilitychange / pagehide / pageshow / freeze 대응, 음소거 상태 존중)
